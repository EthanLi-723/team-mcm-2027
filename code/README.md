# code 目录约定

建议的文件划分（按功能，不要写成一个巨型脚本）：

| 文件 | 作用 |
|---|---|
| `01_data_clean.py` | 读原始数据、清洗、存到 `data/processed/` |
| `02_model_xxx.py` | 主模型：求解 + 输出结果 |
| `03_sensitivity.py` | 灵敏度分析 / 稳健性检验 |
| `plot_setup.py` | 画图统一样式（已提供） |

原则：

1. 每个脚本都能**从头到尾独立跑通**，不要依赖上一次运行的中间状态
2. 路径统一用相对路径，从仓库根目录运行
3. 随机过程固定随机种子，保证结果可复现
4. 有用的中间结果存文件，不要只打印在终端里

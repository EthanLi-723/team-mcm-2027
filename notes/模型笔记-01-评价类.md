# 模型笔记 01 · 评价类：熵权法 + TOPSIS

配套代码：`code/example_01_topsis.py`
跑法：在仓库根目录执行 `python code/example_01_topsis.py`

## 这类问题长什么样

题目里出现这些说法，基本就是评价类：

- "对若干方案/城市/供应商/医院进行综合排序"
- "建立指标体系，评估……的优劣"
- "给出推荐顺序，并说明理由"

典型赛题：城市宜居性排名、医疗资源分配优先级、供应商选择、政策效果评估。

## 为什么这两个模型常一起用

| 环节 | 用什么 | 解决什么 |
|---|---|---|
| 定权重 | 熵权法 | 客观定权，避免"我觉得这个指标更重要" |
| 排顺序 | TOPSIS | 算每个方案离"理想最优"有多远 |

单独用任何一个都能写论文，但**合起来是标准套路**：熵权法定权 → TOPSIS 排序。

## 步骤（背下来，比赛直接用）

1. **建指标体系**：列出指标，并标清方向——效益型（越大越好）还是成本型（越小越好）
2. **正向化**：把成本型指标转成"越大越好"
3. **标准化**：极差法统一到 [0, 1]，消除量纲
4. **熵权法定权**：某指标在方案之间差别越大 → 信息越多 → 权重越高
5. **TOPSIS**：构造加权矩阵 → 找理想最优/最劣 → 算欧氏距离 → 贴近度 C = d⁻/(d⁺+d⁻)
6. **排序**：贴近度越大越好

## 三个最容易踩的坑

1. **忘记标记指标方向**：成本型指标不正向化，排名会直接反过来
2. **权重全为 0 或极端集中**：如果某个指标所有方案数值相同，熵权法会给它权重 0——这不是 bug，要在论文里说明
3. **指标数量与方案数量失衡**：方案太少（比如 3 个）时，熵权法算出来的权重不稳定，最好补充说明或换主客观组合赋权

## 论文里怎么写才加分

- 权重表 + 排名图，两张图必须有
- **做一次灵敏度分析**：把权重上下浮动 10%，看排名是否变化。这一步做了，档次立刻不一样
- 和另一种方法（如 AHP、主成分分析）对比排序结果，说明结论稳健

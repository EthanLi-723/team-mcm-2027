## 先判断：该用哪种预测方法

这一步比写代码重要得多。比赛里选错方法，后面全白做。

| 你的数据情况 | 首选方法 | 理由 |
|---|---|---|
| 只有 4—10 个点、整体单调上升或下降 | **GM(1,1)** | 小样本也能建模，不需要统计假设 |
| 20 个以上的点、有时间趋势 | 线性/多项式回归、ARIMA | 数据够多，统计方法更可靠 |
| 有多个影响因素（人口、GDP、气温…） | 多元回归、灰色关联 + 回归 | 要解释"为什么" |
| 数据有明显季节波动 | 季节性分解、SARIMA | 普通模型抓不住周期 |
| 非线性、数据量大 | LSTM、随机森林 | 需要足够样本，容易过拟合 |

**一句话**：小样本单调序列 → GM(1,1)；大样本带趋势 → ARIMA；要找影响关系 → 回归。

## GM(1,1) 的六个步骤

1. **级比检验**：算 σ(k)=x(k-1)/x(k)，落在 (e^(-2/(n+1)), e^(2/(n+1))) 内才适合建模
2. **累加生成（1-AGO）**：把原始序列累加成单调上升序列，弱化随机性
3. **紧邻均值生成**：z(k) = 0.5·(x¹(k)+x¹(k-1))
4. **最小二乘求参数**：解出发展系数 a 和灰作用量 b
5. **时间响应函数**：x¹(k+1) = (x¹(1) − b/a)·e^(−ak) + b/a
6. **累减还原**：把预测值还原成原始量纲，再做后验差检验

## 检验怎么看（写进论文的硬指标）

| 指标 | 含义 | 合格线 |
|---|---|---|
| 后验差比 C | 残差波动 / 原始数据波动 | C < 0.35 一级，< 0.5 二级 |
| 小误差概率 P | 残差落在允许范围的比例 | P > 0.95 一级 |
| MAPE | 平均相对误差 | < 10% 很好，< 20% 可用 |

**注意**：a 不能太大。一般 |a| < 0.3 时预测才可信；a 接近 -1 说明序列变化过猛，模型不可用。

## 三个坑

1. **不做级比检验直接建**：序列不合适时 GM(1,1) 会给出离谱结果，论文里会被质疑
2. **只报预测值不报检验**：评委一定会看 C 和 P，缺了就是硬伤
3. **用 GM(1,1) 预测波动序列**：它天生假设单调趋势，波动大的数据要用 ARIMA

## 论文里怎么写才加分

- **两个模型对比**：GM(1,1) 和线性回归各跑一遍，报 MAPE，说明为什么选它
- **画一张对比图**：实际值 + 两条拟合曲线 + 预测区间阴影（示例代码已经画好）
- **讨论适用边界**：说明当数据超过 15 个点时应该换 ARIMA，体现你的判断力

# 论文骨架（美赛 / 国赛通用）

> 美赛：英文；国赛：中文。结构一样，语言不同。

## 一、摘要 Summary

评委第一眼看的就是这一页，必须最后写、写得最好。

- 第一段：问题背景 + 我们做了什么（3 句以内）
- 第二段：每个问的模型与主要结论（一问一句，带关键数字）
- 第三段：模型的亮点与稳健性
- 关键词：4—6 个

## 二、问题重述与假设

1. 问题背景（不要抄题，压缩到一段）
2. 我们的工作（流程图或分点）
3. 模型假设：每条假设都要能对应后面的推导或说明为什么合理
4. 符号说明（表）

## 三、模型建立与求解

按问题逐个写，每问统一结构：

1. 建模思路（为什么选这个模型）
2. 数学表达（公式）
3. 求解方法与步骤
4. 结果（图 + 表 + 关键数字）
5. 结果分析（这个数字说明了什么）

## 四、灵敏度分析与模型检验

这一节最容易拉开差距：

- 关键参数上下浮动 ±10%，结论是否改变
- 换一种方法/模型，结论是否一致
- 模型局限与适用条件

## 五、模型评价与推广

- 优点（3 条，要具体）
- 缺点（3 条，要诚实）
- 可以怎么推广

## 六、参考文献与附录

- 参考文献：统一格式，正文里要真的引用
- 附录：放代码和较长的推导

## 写作纪律

1. **图比字值钱**：每一问至少一张图
2. 每张图有编号、标题、正文里引用
3. 摘要写不出具体数字，说明模型还没跑出结果
4. 最后一晚只做两件事：改摘要、查格式

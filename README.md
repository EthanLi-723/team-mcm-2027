## 协作规矩

1. 不直接在 `main` 上改，每人一个分支：`dev-<你的名字>`
2. 每完成一块就提交一次，提交信息写清楚做了什么
3. 每天开始工作前先 `git pull`，收工前 `git push`
4. 数据文件超过 50MB 不要进仓库，改用网盘并在 `data/README.md` 里记链接
5. 论文正在写的那一版不删旧版，用提交历史回溯

详细命令见 [notes/git-速查.md](notes/git-速查.md)
